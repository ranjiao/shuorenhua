# 中文 AI 高频词分级词表

判定原则：**看作用和上下文，不凭词语判来源。** 一级词出现时检查是否说清事实；二级词密集共现时检查是否有重复铺陈。真实术语、政策提法、引用与作者有意选择优先保护。多个词聚集也不证明作者使用了 AI。

改写时不是机械替换同义词，而是问：这个词背后想说的具体事实是什么？把那个事实写出来。

也检查没有固定词形的修辞动作：只宣布重要、预告洞察、无端纠正、反复承诺有用或总结。没有这些词也可能有模板问题；出现「可能」「重要」也可能在交代必要信息。

## 一级：出现时检查具体含义

这组词常见于行业和报告语体。检查它们在当前场景中是否准确、具体，不因命中词表就替换。

**黑话动词：** 赋能、深耕、聚焦、助力、打造、引领、驱动、拥抱（比喻）、锚定、发力、破局、跃迁

**黑话名词：** 抓手、闭环、底层逻辑、顶层设计、方法论（泛化使用）、护城河（泛化使用）、组合拳、生态（泛化使用）、矩阵（非数学）、心智（营销语）、颗粒度、载体

**万能修饰：** 全方位、多维度、立体化、一站式、沉浸式、全链路、端到端（非技术语境）、系统性（泛化使用）

**口号缩略：** 降本增效、提质增效、数智化、新质生产力、高质量发展（非政策原文语境）

**条件示例：** 下表右列仅在用户或原文已提供对应事实时成立，不能从左列推导出来。没有依据时删空话或保留朴素表述，不补写行业、数字和功能。

| AI 写法 | 问题 | 人话 |
|---------|------|------|
| 赋能一线员工 | 谁给谁什么能力？ | 让门店店员自己能改价，不用等总部审批 |
| 打造内容生态 | 做了什么？ | 上线了创作者分成，拉来了 200 个签约作者 |
| 形成业务闭环 | 什么环？ | 从下单到售后都在一个系统里，不用导表 |
| 以数据为抓手 | 具体动作？ | 每周看一次流失用户名单，挨个回访 |

## 二级：密集共现时可疑

反复出现时，检查它们是否承担连接、限定或强调的作用。只删重复铺陈，不按词数设判断阈值。

**连接词：** 此外、另外、与此同时、除此之外、不仅如此、更重要的是、值得注意的是、值得一提的是、不可否认、毫无疑问、众所周知、事实上、总的来说、综上所述

**程度词：** 至关重要、极为关键、意义重大、显著、大幅、极大地、有效地、充分、切实、扎实

**书面动词：** 彰显、凸显、擘画、赋予、承载、依托、立足、着力、致力于、旨在

**抽象名词：** 格局、版图、图景、篇章、脉络、维度、路径（比喻）、动能、势能（非物理）

## 套话短语：几乎总能删

**开头套话：**
- 「随着……的不断发展」「在当今……的时代」「在……的大背景下」→ 删掉，直接说事
- 「近年来」「一直以来」→ 有具体时间就写时间，没有就删
- 「众所周知」「不言而喻」→ 既然众所周知就不用写；其实不众所周知就更不能这么写

**中间套话：**
- 「作为……的重要组成部分」→ 说它具体做什么
- 「从……的角度来看」「就……而言」→ 多数可删
- 「在……的过程中」→ 直接说动作
- 「具有……的特点/能力/优势」→ 「能」「是」

**收尾套话：**
- 「未来可期」「前景广阔」「大有可为」→ 删，或写真实计划
- 「让我们拭目以待」「时间会给出答案」→ 删
- 「砥砺前行」「行稳致远」「久久为功」→ 删（公文原文除外）

## 翻译腔结构

下列结构可能使表达绕远，可按场景简化；技术和学术文本中的准确用法应保留：

| 翻译腔 | 人话 |
|--------|------|
| 进行一个测试 | 测一下 |
| 实现对数据的处理 | 处理数据 |
| 该功能被广泛地使用 | 很多人用这个功能 |
| 在性能方面表现良好 | 性能不错 |
| 作为一名工程师而言 | 工程师…… / 我做工程的…… |
| 其结果表明 | 结果是 / 研究发现 |
| 一个基于 X 的面向 Y 的 Z | Z 用 X 做，给 Y 用 |

检查这些结构是否让句子变长却没有增加信息。正常的书面表达保留，不单凭出现频率判断。
